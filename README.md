# Local Mini Store Project
Disclaimer: This project is a submission to a test, use this repository at your own risk.

Local development
-----------------

Open the folder in a browser (or serve with a static server). The app uses localStorage for products and cart.

Pushing to the remote `feature` branch
-------------------------------------

Run these commands from the repo root to create a `feature` branch, commit, and push to the remote `origin`:

```bash
git checkout -b feature
git add .
git commit -m "Add mini-store index, cart, checkout pages and cart logic"
git push -u origin feature
```

If the remote repository is not configured, add it with:

```bash
git remote add origin https://github.com/Tunne097/mini-store.git
git push -u origin feature
```
